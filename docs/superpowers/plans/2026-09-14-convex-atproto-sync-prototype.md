# Convex atproto Sync Prototype Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire `typescript/apps/convex-test` up as a client of habitat's proposal-0016 permissioned-spaces sync protocol: log in via sap-brokered atproto OAuth, sync records into per-collection Convex tables via sap's webhook, and write records back via sap's `/proxy/network.habitat.space.putRecord` relay.

**Architecture:** sap is the only thing that talks to pear. `convex-test` (TanStack Start, Node-hosted, not Cloudflare) ports chalk's proven sap-relay auth pattern (`typescript/apps/chalk/src/server/sapClient.ts` + `login.tsx` + `session.callback.tsx`) using `@tanstack/react-start`'s built-in `useSession`. A small script generates one Convex table per declared collection from that collection's lexicon. A Convex HTTP action receives sap's webhook deliveries and upserts rows; a Convex mutation+action pair writes optimistically then relays through sap.

**Tech Stack:** TypeScript, Convex (`convex/server`, `convex/values`, `convex/react`), TanStack Start (`@tanstack/react-start/server` `useSession`), Node `fetch`, Go (`cmd/sap`, unmodified except `moon.yml` dev wiring).

**Spec:** `docs/superpowers/specs/2026-09-14-convex-atproto-sync-prototype-design.md`

## Global Constraints

- sap is the only caller of pear; Convex never calls pear directly (spec: Architecture overview).
- One logged-in DID at a time, no multi-session UI (spec: Non-goals).
- Lexicon `$ref`/`union`/`blob` fields map to `v.any()` in generated schemas — no cross-file resolution (spec: Schema generation).
- No production auth hardening; the `return_to` open-redirect shape and sap's internal-port trust model are inherited as-is (spec: Non-goals).
- This is prototype code: validation is manual end-to-end (curl, Convex dashboard, browser), not an automated test suite — `convex-test` isn't Moon-managed and has no coverage requirement (spec: Testing / validation).
- Target collection for this pass: `network.habitat.relationship.userRelation` (NSID), lexicon at `lexicons/network/habitat/relationship/userRelation.json` — plain string/enum fields, no blob handling needed.
- Webhook payload shape is fixed by `cmd/sap/webhook.go`'s `webhookPayload` struct: `{id: number, uri: string, value: object}` — no `cid`/`rev` included. `cid`/`rev` are only ever known from a direct `putRecord` response, so they're optional columns populated only by the mutation path.
- sap's `/proxy/<nsid>` contract (`cmd/sap/server.go:handleProxy`): request needs header `Habitat-Did: <did>` (required) and forwards method/query/body verbatim to `/xrpc/<nsid>` on the member's PDS-tracked host; response status/body are passed through unchanged.
- sap's `/session/add` (`cmd/sap/server.go:handleAddSession`): `POST {handle, return_to}` → `{redirect_url}`.
- sap's `/space/track` (`cmd/sap/server.go:handleTrackSpace`): `POST` with header `Habitat-Did: <did>`, body `{space: <at-uri>}` → `200` on success.
- All calls to sap's internal port additionally need `Authorization: Basic base64(":"+secret)` when `SAP_INTERNAL_AUTH_SECRET` is configured — send it whenever the env var is set, omit otherwise (mirrors chalk's `sapAuthHeaders`).

```js
// typescript/apps/convex-test/scripts/gen-schema.mjs
import { readFileSync, writeFileSync } from "node:fs";
import { fileURLToPath } from "node:url";
import path from "node:path";
import { collections } from "../collections.config.mjs";

const __dirname = path.dirname(fileURLToPath(import.meta.url));

function lexiconTypeToValidator(prop) {
  switch (prop.type) {
    case "string":
      return "v.string()";
    case "integer":
      return "v.number()";
    case "boolean":
      return "v.boolean()";
    case "bytes":
      return "v.bytes()";
    case "cid-link":
      return "v.string()";
    case "array":
      return `v.array(${lexiconTypeToValidator(prop.items)})`;
    case "object": {
      const required = new Set(prop.required ?? []);
      const fields = Object.entries(prop.properties ?? {})
        .map(([name, sub]) => {
          const validator = lexiconTypeToValidator(sub);
          return `    ${name}: ${required.has(name) ? validator : `v.optional(${validator})`},`;
        })
        .join("\n");
      return `v.object({\n${fields}\n  })`;
    }
    // $ref, union, blob, and anything else: not resolved for this prototype.
    default:
      return "v.any()";
  }
}

function generateTable(collection) {
  const lexiconPath = path.join(__dirname, "..", collection.lexiconPath);
  const lexicon = JSON.parse(readFileSync(lexiconPath, "utf8"));
  const record = lexicon.defs.main.record;
  const required = new Set(record.required ?? []);

  const fields = Object.entries(record.properties ?? {})
    .map(([name, prop]) => {
      const validator = lexiconTypeToValidator(prop);
      return `    ${name}: ${required.has(name) ? validator : `v.optional(${validator})`},`;
    })
    .join("\n");

  return `  ${collection.table}: defineTable({
    uri: v.string(),
    did: v.string(),
    cid: v.optional(v.string()),
    rev: v.optional(v.string()),
    syncStatus: v.union(v.literal("pending"), v.literal("confirmed"), v.literal("failed")),
${fields}
  }).index("by_uri", ["uri"]),`;
}

const tables = collections.map(generateTable).join("\n");

const output = `// GENERATED by scripts/gen-schema.mjs from collections.config.mjs — do not hand-edit.
// Regenerate with: node scripts/gen-schema.mjs
import { defineSchema, defineTable } from "convex/server";
import { v } from "convex/values";

export default defineSchema({
${tables}
});
`;

writeFileSync(path.join(__dirname, "..", "convex", "schema.ts"), output);
console.log("wrote convex/schema.ts");
```

```typescript
// typescript/apps/convex-test/src/server/sapClient.ts
const habitatDIDHeader = "Habitat-Did";

function requireEnv(name: string): string {
  const value = process.env[name];
  if (!value) throw new Error(`${name} is not set`);
  return value;
}

export function sapAuthHeaders(): Record<string, string> {
  const secret = process.env.SAP_INTERNAL_AUTH_SECRET;
  if (!secret) return {};
  return { Authorization: `Basic ${Buffer.from(`:${secret}`).toString("base64")}` };
}

export async function startLogin(
  handle: string,
  returnPath = "/session/callback",
): Promise<string> {
  const base = requireEnv("SITE_URL");
  const sapUrl = requireEnv("SAP_INTERNAL_URL");
  const res = await fetch(`${sapUrl}/session/add`, {
    method: "POST",
    headers: { "content-type": "application/json", ...sapAuthHeaders() },
    body: JSON.stringify({ handle, return_to: `${base}${returnPath}` }),
  });
  if (!res.ok) {
    throw new Error(`failed to start login (${res.status}): ${await res.text()}`);
  }
  const { redirect_url } = (await res.json()) as { redirect_url: string };
  return redirect_url;
}

export class SapClient {
  constructor(private did: string) {}

  private get base(): string {
    return requireEnv("SAP_INTERNAL_URL");
  }

  async call<T>(
    nsid: string,
    method: "GET" | "POST",
    payload: Record<string, unknown>,
  ): Promise<T> {
    const base = `${this.base}/proxy/${nsid}`;
    let url = base;
    let body: string | undefined;
    const headers: Record<string, string> = {
      [habitatDIDHeader]: this.did,
      ...sapAuthHeaders(),
    };
    if (method === "GET") {
      const qs = new URLSearchParams();
      for (const [k, v] of Object.entries(payload)) {
        if (v !== undefined && v !== null) qs.set(k, String(v));
      }
      url = `${base}?${qs.toString()}`;
    } else {
      body = JSON.stringify(payload);
      headers["content-type"] = "application/json";
    }
    const res = await fetch(url, { method, body, headers });
    if (!res.ok) {
      throw new Error(`${nsid} failed (${res.status}): ${await res.text()}`);
    }
    const text = await res.text();
    return (text ? JSON.parse(text) : undefined) as T;
  }

  async trackSpace(spaceUri: string): Promise<void> {
    const res = await fetch(`${this.base}/space/track`, {
      method: "POST",
      headers: {
        [habitatDIDHeader]: this.did,
        "content-type": "application/json",
        ...sapAuthHeaders(),
      },
      body: JSON.stringify({ space: spaceUri }),
    });
    if (!res.ok) {
      throw new Error(`trackSpace failed (${res.status}): ${await res.text()}`);
    }
  }
}
```

```typescript
// typescript/apps/convex-test/convex/records.ts
import { internalMutation, mutation, query } from "./_generated/server";
import { v } from "convex/values";
import { collections } from "../collections.config.mjs";

const collectionByNsid = new Map(collections.map((c) => [c.nsid, c]));

// at://<did>/<collection>/<rkey>
function parseUri(uri: string): { did: string; collection: string; rkey: string } {
  const match = /^at:\/\/([^/]+)\/([^/]+)\/([^/]+)$/.exec(uri);
  if (!match) throw new Error(`unparseable at-uri: ${uri}`);
  const [, did, collection, rkey] = match;
  return { did, collection, rkey };
}

export const upsertFromWebhook = internalMutation({
  args: { uri: v.string(), value: v.any() },
  handler: async (ctx, { uri, value }) => {
    const { did, collection } = parseUri(uri);
    const target = collectionByNsid.get(collection);
    if (!target) {
      // Not a collection this prototype cares about — skip, not an error.
      return;
    }
    if (target.table !== "userRelations") {
      throw new Error(`unhandled table ${target.table} — add a case below`);
    }
    const existing = await ctx.db
      .query("userRelations")
      .withIndex("by_uri", (q) => q.eq("uri", uri))
      .unique();
    const row = {
      uri,
      did,
      syncStatus: "confirmed" as const,
      subject: value.subject,
      relation: value.relation,
      createdAt: value.createdAt,
    };
    if (existing) {
      await ctx.db.patch(existing._id, row);
    } else {
      await ctx.db.insert("userRelations", row);
    }
  },
});

export const list = query({
  args: {},
  handler: async (ctx) => ctx.db.query("userRelations").collect(),
});
```

```typescript
// (add `action` to the existing `import { internalMutation, mutation, query } from "./_generated/server"` line from Task 3)
import { action } from "./_generated/server";
import { internal } from "./_generated/api";

export const write = mutation({
  args: {
    space: v.string(),
    repo: v.string(),
    subject: v.string(),
    relation: v.string(),
  },
  handler: async (ctx, { space, repo, subject, relation }) => {
    const uri = `pending:${crypto.randomUUID()}`; // placeholder until putRecord returns the real at-uri
    const recordId = await ctx.db.insert("userRelations", {
      uri,
      did: repo,
      syncStatus: "pending",
      subject,
      relation,
    });
    await ctx.scheduler.runAfter(0, internal.records.pushToSap, {
      recordId,
      space,
      repo,
      subject,
      relation,
    });
    return recordId;
  },
});

export const pushToSap = action({
  args: {
    recordId: v.id("userRelations"),
    space: v.string(),
    repo: v.string(),
    subject: v.string(),
    relation: v.string(),
  },
  handler: async (ctx, { recordId, space, repo, subject, relation }) => {
    const sapUrl = process.env.SAP_INTERNAL_URL;
    if (!sapUrl) throw new Error("SAP_INTERNAL_URL is not set");
    const secret = process.env.SAP_INTERNAL_AUTH_SECRET;
    const headers: Record<string, string> = {
      "Habitat-Did": repo,
      "content-type": "application/json",
    };
    if (secret) {
      headers.Authorization = `Basic ${Buffer.from(`:${secret}`).toString("base64")}`;
    }
    const res = await fetch(`${sapUrl}/proxy/network.habitat.space.putRecord`, {
      method: "POST",
      headers,
      body: JSON.stringify({
        space,
        repo,
        collection: "network.habitat.relationship.userRelation",
        record: { subject, relation, createdAt: new Date().toISOString() },
      }),
    });
    if (!res.ok) {
      await ctx.runMutation(internal.records.markFailed, { recordId });
      throw new Error(`putRecord failed (${res.status}): ${await res.text()}`);
    }
    const { uri, cid } = (await res.json()) as { uri: string; cid: string };
    await ctx.runMutation(internal.records.confirmWrite, { recordId, uri, cid });
  },
});

export const confirmWrite = internalMutation({
  args: { recordId: v.id("userRelations"), uri: v.string(), cid: v.string() },
  handler: async (ctx, { recordId, uri, cid }) => {
    await ctx.db.patch(recordId, { uri, cid, syncStatus: "confirmed" });
  },
});

export const markFailed = internalMutation({
  args: { recordId: v.id("userRelations") },
  handler: async (ctx, { recordId }) => {
    await ctx.db.patch(recordId, { syncStatus: "failed" });
  },
});
```

```tsx
import { createFileRoute, redirect } from "@tanstack/react-router";
import { createServerFn } from "@tanstack/react-start";
import { z } from "zod";
import { useAppSession } from "@/server/session";

const setSessionDidFn = createServerFn({ method: "POST" })

export const Route = createFileRoute("/session/callback")({

});
```

```tsx
// typescript/apps/convex-test/src/routes/index.tsx — replace existing content
import { createFileRoute, Link } from "@tanstack/react-router";
import { createServerFn } from "@tanstack/react-start";
import { useQuery, useMutation } from "convex/react";
import { useState } from "react";
import { api } from "../../convex/_generated/api";
import { useAppSession } from "@/server/session";

const whoamiFn = createServerFn({ method: "GET" }).handler(async () => {
  const session = await useAppSession();
  return { did: session.data.did ?? null };
});

export const Route = createFileRoute("/")({
  loader: () => whoamiFn(),
  component: Home,
});

function Home() {
  const { did } = Route.useLoaderData();
  const records = useQuery(api.records.list, {});
  const write = useMutation(api.records.write);
  const [subject, setSubject] = useState("");
  const [relation, setRelation] = useState("writer");
  const [space, setSpace] = useState("");

  if (!did) {
    return (
      <p>
        Not signed in. <Link to="/login">Sign in</Link>
      </p>
    );
  }

  return (
    <div style={{ maxWidth: 640, margin: "2rem auto" }}>
      <p>Signed in as {did}</p>
      <form
        onSubmit={(e) => {
          e.preventDefault();
          void write({ space, repo: did, subject, relation });
        }}
      >
        <input placeholder="space at-uri" value={space} onChange={(e) => setSpace(e.target.value)} />
        <input placeholder="subject did" value={subject} onChange={(e) => setSubject(e.target.value)} />
        <input placeholder="relation" value={relation} onChange={(e) => setRelation(e.target.value)} />
        <button type="submit">Write</button>
      </form>
      <ul>
        {(records ?? []).map((r) => (
          <li key={r._id}>
            {r.subject} — {r.relation} ({r.syncStatus})
          </li>
        ))}
      </ul>
    </div>
  );
}
```
