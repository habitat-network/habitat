# Build on Habitat

Habitat is an open-source, self-hostable data ownership layer for
organizations, built on [AT Protocol](https://atproto.com) primitives:
identities, user-owned repositories, fine-grained permissions, and syncing.

## Start here

1. **[What is Habitat?](/docs/habitat)** — what the platform is and who it
   is for.
2. **[Quickstart](/docs/space-proxy/getting-started)** — point an atproto
   OAuth client at Habitat as its identity resolver and sign a user in.
   Runs against our hosted instance; nothing to install.
3. **[Building on Habitat](/docs/building/intro)** — identities and auth,
   permissions, data, and sync.
4. **[HTTP API reference](/docs/api)** — every XRPC endpoint.
5. **[Self-hosting](/docs/guides/self-hosting)** — run your own instance
   with Docker.
